# Project Memory

## Core
Medical study app "StudyBuddy AI". Inter font, SF Pro fallback. Medical blue/teal palette.
Light/dark theme with persistence. Glass-card style, gradient background. No markdown in AI output.
Output parsed into SUMMARY, MEMORY HOOKS, KEY POINTS, FLASHCARDS sections. Quiz mode available.
Usage limit: 10/day localStorage, then Lite Mode. Study history saved locally.
